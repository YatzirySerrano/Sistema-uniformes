# Js Composables

## EstadoVisibleUnidad tiene 7 casos: Reparación e Inservible son estados separados (ya NO se agrupan)
Hasta 2026-09, `condicion=Inservible` resolvía al mismo estado visible que `EnReparacion` (`EstadoVisibleUnidad::Reparacion`), mostrando el badge/descripción de "En reparación" ("Fuera de operación y con diagnóstico o seguimiento abierto") para una unidad que NO necesariamente está en diagnóstico. Corregido: `EstadoVisibleUnidad` ahora tiene 7 casos (se agregó `Inservible = 'inservible'`, etiqueta "Inservible", descripción "Fuera de operación y no disponible para uso."). `resolver()` ya no agrupa `EnReparacion`/`Inservible`. Impacto que SÍ se tocó: `UnidadActivoController::aplicarFiltroEstadoVisible()` (nuevo `match` arm), `PaletaGraficas::estadoUnidad()` (nuevo color naranja `#f97316`, MISMO valor en `resources/js/lib/estadoVisibleUnidad.ts` y `useGraficasDashboard.ts` — mantener sincronizados). Impacto que NO requirió cambios (auto-adaptan por iterar `EstadoVisibleUnidad::cases()` genéricamente): `ServicioReportes::metricasUnidades()`, `ReporteController::graficasInventario()`, `UnidadActivoController::graficasUnidades()`, `ServicioDashboard::unidadesPorEstado()`/`colapsarUnidadesPorVisible()`. Deliberadamente SIN cambio: `ServicioDashboard::kpisUnidades()['unidades_en_reparacion']` sigue siendo SÓLO EnReparacion (nunca sumar Inservible ahí) — así se mantiene coherente con el link del KPI en Panel.vue (`?estado_visible=reparacion`), seguido el mismo principio de `[[activo-detalle-kpi-no-disponible]]`: la cifra de un KPI y el filtro de su link deben representar EXACTAMENTE el mismo conjunto, nunca un superconjunto. Las unidades Inservible en el Dashboard sólo aparecen en el desglose completo (`unidades_por_estado`, ahora 7 categorías), no en las 5 tarjetas KPI resumen — decisión consciente para no inventar una tarjeta nueva. El badge secundario de "condición" en `Unidades.vue`/`UnidadDetalle.vue` (se muestra si `condicion !== funcionando`) queda REDUNDANTE con el badge principal para Inservible (como ya ocurría antes para Perdido/Robado) — no se corrigió, es cosmético y preexistente.
